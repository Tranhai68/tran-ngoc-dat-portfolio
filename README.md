# Portfolio & Executive CV — Trần Ngọc Đạt

> **Trưởng Phòng Kinh Doanh | Digital Marketing | Fashion Retail**  
> 7 năm kinh nghiệm Kinh doanh Thời trang nữ | 5 năm Digital Advertising | Tăng trưởng quy mô 10X (15 tỷ → 150 tỷ VNĐ/năm).

Trang Portfolio được thiết kế theo phong cách **Strict Monochrome Editorial (Orvante Style)** sử dụng thuần **HTML5, CSS3, Vanilla JavaScript** (không cần cài đặt thư viện hay build step phức tạp).

---

## 🚀 Tính năng nổi bật

1. **Giao diện Monochrome chuẩn Editorial**: Tỉ lệ chuẩn 1440px theo hệ số biến thiên `u = min(100vw / 1440, 1.333px)`, tương thích mượt mà trên cả máy tính và điện thoại di động (≤ 760px).
2. **Hiệu ứng chữ phát sáng khi cuộn (Scroll-driven Word Lighting)**: Từng từ trong tuyên ngôn kinh doanh tự động chuyển từ `#6f6f6f` sang `#f4f4f4`.
3. **Thanh điều hướng Pill trượt (Sliding Pill Nav)**: Tự động trượt theo con trỏ chuột và trạng thái mục đang xem.
4. **Bộ đếm tự động (Animated Counters)**: Tự động nhảy số `150 TỶ+` và `10X+` khi cuộn tới phần thành tựu.
5. **Hồ sơ năng lực chi tiết (Dossier Breakdown)**: Đầy đủ 4 năm tại DEZUS, 5 năng lực chuyên môn cốt lõi, định hướng quản trị cấp cao và nút sao chép nhanh email.

## 🖼️ Hướng dẫn thay đổi ảnh đại diện chính

Bạn có thể thay thế ảnh chân dung chính bất cứ lúc nào trong file `index.html`:

1. **Cách 1: Dùng ảnh online (URL)**:
   Mở `index.html`, tìm thẻ `id="heroPhotoWrap"` (khoảng dòng 1630):
   ```html
   <div class="hero-photo-wrap" id="heroPhotoWrap">
     <img src="ĐƯỜNG_DẪN_ẢNH_CỦA_BẠN.jpg" alt="Trần Ngọc Đạt - Head of Sales / Growth Director">
   </div>
   ```

2. **Cách 2: Dùng ảnh nội bộ (Local file)**:
   - Thêm ảnh của bạn vào cùng thư mục (ví dụ `avatar.png` hoặc `portrait.jpg`).
   - Đổi `src="avatar.png"`.

## 🌐 Chạy thử trên máy cục bộ

Bạn chỉ cần nhấp đúp trực tiếp vào file `index.html` hoặc chạy máy chủ static bất kỳ:

```bash
# Bằng Python
python3 -m http.server 8000

# Hoặc bằng npx serve
npx serve .
```
Mở trình duyệt tại: `http://localhost:8000`
